    КАК СОБРАТЬ И ЗАПУСТИТЬ МОД В INTELLIJ IDEA

📂 ШАГ 1: ОТКРЫТЬ ПРОЕКТ В IDEA
────────────────────────────────────────────────────────────
1. Запустите IntelliJ IDEA
2. Нажмите "Open" (Открыть)
3. Выберите папку c:\Users\edemw\Desktop\mod
4. Нажмите "OK"
5. Подождите, пока IDEA загрузит проект (внизу будет прогресс)

⚙️ ШАГ 2: НАСТРОИТЬ ПРОЕКТ (ПЕРВЫЙ РАЗ)
────────────────────────────────────────────────────────────
1. Откройте правую панель "Gradle" (справа на экране)
2. Разверните: mod → Tasks → forgegradle runs
3. Дважды кликните на "genIntellijRuns"
4. Дождитесь завершения (может занять 5-10 минут при первом запуске)
5. После завершения нажмите кнопку обновления (🔄) в окне Gradle

Готово! Теперь у вас появятся конфигурации запуска.

🔨 ШАГ 3: СОБРАТЬ МОД
────────────────────────────────────────────────────────────
ВАРИАНТ А - Через Gradle панель:
   1. Откройте панель Gradle (справа)
   2. Разверните: mod → Tasks → build
   3. Дважды кликните на "build"
   4. Дождитесь "BUILD SUCCESSFUL"
   5. Готовый мод: build\libs\examplemod-1.0.0.jar

ВАРИАНТ Б - Через терминал в IDEA:
   1. Внизу нажмите вкладку "Terminal"
   2. Введите команду:
      
      gradlew build
      
   3. Нажмите Enter
   4. Дождитесь "BUILD SUCCESSFUL"

🎮 ШАГ 4: ЗАПУСТИТЬ МАЙНКРАФТ С МОДОМ (ДЛЯ ТЕСТИРОВАНИЯ)
────────────────────────────────────────────────────────────
Вам НЕ НУЖНО собирать мод для тестирования! Можно сразу запустить:

1. В правом верхнем углу найдите выпадающий список конфигураций
2. Выберите "runClient"
3. Нажмите зеленую кнопку ▶️ (Run) или Shift+F10
4. Подождите загрузки (первый раз может занять 5-10 минут)
5. Откроется Minecraft с вашим модом!

🧪 КАК ПРОВЕРИТЬ, ЧТО МОД РАБОТАЕТ?
────────────────────────────────────────────────────────────
В запущенной игре:

1. Создайте новый мир (креатив)
2. Откройте инвентарь (E)
3. В поиске напишите "super"
4. Вы увидите "Super Apple" с фиолетовым названием!

⚡ БЫСТРАЯ РАЗРАБОТКА
────────────────────────────────────────────────────────────
Вы можете изменять код БЕЗ перезапуска игры!

1. Запустите игру через "runClient"
2. Измените код в ExampleMod.java
3. Нажмите Ctrl+F9 (Build Project)
4. Код обновится автоматически в запущенной игре!

❌ ВОЗМОЖНЫЕ ПРОБЛЕМЫ
────────────────────────────────────────────────────────────
ПРОБЛЕМА: "Task 'genIntellijRuns' not found"
РЕШЕНИЕ: Обновите панель Gradle (кнопка 🔄)

ПРОБЛЕМА: "Could not resolve dependencies"
РЕШЕНИЕ: Проверьте интернет-соединение, попробуйте снова

ПРОБЛЕМА: Нет конфигурации "runClient"
РЕШЕНИЕ: Запустите заново "genIntellijRuns"

ПРОБЛЕМА: Игра не запускается
РЕШЕНИЕ: Убедитесь, что у вас установлена Java 17
         (File → Project Structure → SDK → выберите Java 17)

📦 УСТАНОВКА МОДА В ОБЫЧНЫЙ МАЙНКРАФТ
────────────────────────────────────────────────────────────
Чтобы играть с модом вне IDEA:

1. Соберите мод (ШАГ 3)
2. Возьмите файл: build\libs\examplemod-1.0.0.jar
3. Установите Minecraft Forge 1.20.1
4. Скопируйте .jar файл в папку mods Minecraft
   (обычно: %appdata%\.minecraft\mods)
5. Запустите Minecraft с профилем Forge
